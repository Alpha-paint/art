# Планувальник мистецтва: навчальна програма і КТП

Сторінка приймає модульну програму (DOCX, PDF або текст), виділяє модулі й теми,
складає уроки з датами за вашим розкладом і віддає файл Word.

Файли проєкту:
- `index.html` — увесь застосунок в одному файлі;
- `api/generate.js` — серверна функція, що звертається до Claude (ключ лишається на сервері);
- `vercel.json`, `package.json` — налаштування; збірка не потрібна.

## Розгортання на Vercel

1. Створіть репозиторій на GitHub і завантажте в нього вміст цієї папки.
2. На vercel.com: Add New → Project → оберіть репозиторій → Deploy (Framework Preset: Other).
3. Project → Settings → Environment Variables, додайте:
   - `ANTHROPIC_API_KEY` — ключ із console.anthropic.com (обов'язково);
   - `ACCESS_CODE` — придумайте код доступу (дуже раджу: без нього кожен, хто знає адресу, витрачатиме ваш рахунок);
   - `ANTHROPIC_MODEL` — за потреби інша модель (типово `claude-sonnet-5`).
4. Deployments → Redeploy, щоб змінні набули чинності.
5. Відкрийте адресу `https://назва-проєкту.vercel.app`, введіть код доступу на першому кроці.

## Нотатки

- Чернетка зберігається в браузері (localStorage) і не потрапляє на сервер.
- Довгі програми: за раз читається до 60 000 символів. Для більших вставте розділ із модулями.
- PDF-скани без текстового шару не читаються: вставте текст вручну.
- Канікули й свята задаються вручну на кроці 3.
- Функція чекає відповідь Claude до 60 с на частину плану (до 8 уроків); більшого ліміту на безкоштовному тарифі може не бути.
